# Keyword map — Aditya Kumar

_Research date: 2026-11-18. Data source: SERP observation (web search). Semrush was connected but had no API
units, so **search volumes are not measured**. Re-run with Google Search Console data after 4–6 weeks._

## What the SERPs showed
- **"Aditya Kumar full stack developer portfolio"**: ~15 different people named Aditya Kumar on page 1–2
  (Contra, Peerlist, Devfolio, many `*.vercel.app` portfolios). eraditya.vercel.app appeared at the bottom
  (≈ positions 19–20). The bare name is **not** a realistic target; disambiguated variants are.
- **"Aditya Kumar developer Barabanki"**: no developer results at all (real-estate news only) → open niche, easy win.
- **"MERN stack developer Lucknow" / "Next.js developer Lucknow"**: agencies + marketplaces (Fiverr, Hubstaff
  Talent, Twine, Truelancer, Upwork, Freelancermap, Jobbers) and job boards. A personal site can't win the head
  term quickly → win it **through marketplace profiles** that link back.

## Not targeting (and why)
- Bare "full stack developer", "react developer", "software developer": national head terms owned by job
  boards, course sites and Wikipedia; not where hires come from.
- "Best/top developer in Lucknow": superlative, unprovable, and agencies dominate it.
- Other cities (Delhi, Noida…): no presence there; doorway pages would be spam.
